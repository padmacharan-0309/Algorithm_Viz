About ALGO VIZ

What is Algorithm Visualization?

Algorithm visualization transforms abstract computer science procedures into dynamic visual representations, making execution flow, memory swaps, partitions, and state transitions intuitive and tangible.

Why Visualization Helps Learning

Rather than memorizing asymptotic complexity tables, seeing pointer movements, recursion stacks, and edge relaxations in real time bridges theoretical intuition with actual computational behavior.

Supported Algorithms

  • Sorting: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort, Heap Sort
  • Searching: Linear Search, Binary Search
  • Graph: Breadth-First Search (BFS), Depth-First Search (DFS), Dijkstra's Algorithm

Architecture & Technologies

Built with pure client-side HTML5, modern CSS3 (Custom Properties & Grid/Flexbox), and ES6+ modules. Features deterministic timeline scrubbing, SVG graph drag-and-drop, and Web Audio synthesizer feedback.
